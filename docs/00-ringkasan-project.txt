RINGKASAN PROJECT - JEJAK JAJAN
=================================================================
Update terakhir: 22 Oktober 2026
Web online: https://jejak-jajan.vercel.app

APA INI
Web arsip/ensiklopedia jajanan tradisional Indonesia berbasis
komunitas. Siapa pun bisa menambah jajanan: cerita asal-usul, resep,
langkah pembuatan, dan lokasi terakhir terlihat.

MASALAH
Jajanan tradisional makin sulit ditemukan: penjual makin sedikit dan
tidak punya penerus. Resep & ceritanya bisa hilang.

SOLUSI
Arsip online yang diisi bareng-bareng (crowdsourcing), dimoderasi admin.

PEMBEDA (vs Cookpad / TikTok / blog resep)
- Cerita & asal daerah, bukan resep saja
- Label kelangkaan hasil vote komunitas (Umum / Jarang / Langka / Kritis)
- Lokasi penjual "Terakhir Terlihat di" + mini map
- Forum Jajanan: tanya resep/penjual, sejarah, tips, nostalgia
- Bukti komunitas "Sudah coba resep ini?" (Dicoba X orang, Y berhasil)
- Ramah orang tua: teks besar, pilihan ukuran teks, ringan di HP

FITUR (daftar lengkap + status di docs/08-daftar-fitur.txt)
1. Beranda: Jajanan Langka (carousel), Baru Ditambahkan, statistik,
   kotak cari; Katalog dengan cari & filter otomatis
2. Halaman jajanan: cerita, resep, langkah, lokasi + mini map, vote
   kelangkaan, komentar, Sudah coba resep ini?, simpan, bagikan,
   unduh PDF (Premium)
3. Kontribusi: 3 langkah wajib (Info dasar, Cerita, Vote kelangkaan) +
   3 opsional (Resep, Langkah, Lokasi penjual), edit & hapus milik sendiri
4. Forum Jajanan: topik, cari postingan, balasan terbaik, laporkan,
   edit milik sendiri
5. Akun: profil (level kontributor + ringkasan aktivitas), pengaturan
   (ukuran teks, kurangi animasi), Pesan
6. Premium (Rp15.000/bulan atau Rp30.000/3 bulan, bayar QRIS lalu disetujui admin) + iklan
   untuk akun gratis
7. Admin: moderasi + checklist kriteria, laporan, iklan, hapus jajanan,
   ganti foto
8. Kelas Bersama Penjual (segera hadir) + daftar minat
Belum: Masih ada / Sudah tidak ada, Lapor jajanan, pembayaran asli.

ROLE
- User belum login : lihat semua konten
- User gratis      : kontribusi, simpan, vote, komentar, forum (+ iklan)
- User Premium     : + bebas iklan, unduh resep PDF, lencana Premium
- Admin            : moderasi + otomatis Premium (lencana "Admin")

MODEL BISNIS (BMC: docs/10, versi slide: docs/10b, detail: docs/06)
Arsip tetap gratis (tidak dikunci). Sumber pendapatan:
- Iklan / sponsor brand bahan kue & UMKM (sudah ada di web)
- Premium Rp15.000/bulan atau Rp30.000/3 bulan (bayar QRIS, disetujui admin)
- Kelas Bersama Penjual (bagi hasil ke penjual)
- Nanti: afiliasi bahan, produk digital, kerja sama pemda

TEKNOLOGI
Next.js 16 + Supabase (auth, database + RLS, storage foto) + Leaflet
(mini map), deploy di Vercel (otomatis tiap merge ke main).
Font: Fraunces, Plus Jakarta Sans, Caveat. Tampilan dioptimalkan untuk
laptop & HP (mis. Samsung A35).
